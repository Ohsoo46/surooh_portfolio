# AI Atelier — 한국경제 AI 교육 포트폴리오

`dist/article.html`, `dist/image.html`, `dist/video.html`, `dist/final.html`은 각각 독립된 HTML 페이지입니다. `dist/index.html`은 기사 페이지와 같은 시작 화면입니다. 브라우저에서 HTML 파일을 직접 열거나 `node preview.mjs`로 로컬 미리보기를 실행할 수 있습니다.

- 기사: 대표 기사와 목록, 전체 글 읽기
- 이미지: 비대칭 갤러리, 작품 확대와 프롬프트 방향
- 영상: 대표 콘텐츠와 스토리보드, 이미지 기반 무음 모션 샘플
- Final project: 프로젝트 개요, 과정과 회고

## 콘텐츠 변경

HTML은 `dist`에서 직접 수정할 수 있습니다. 공통 스타일은 `dist/style.css`, 기사 상세·갤러리 설명·상호작용은 `dist/app.js`에 있습니다. `make-pages.mjs`는 초기 HTML 생성 스크립트입니다. 재실행하면 HTML 직접 수정 사항이 덮어써지므로, 재생성할 경우 이 스크립트의 콘텐츠도 함께 변경하세요.

## 자료 미리보기 범위

내 자료 미리보기는 선택한 로컬 파일을 현재 페이지에서 확인하는 기능입니다. 서버 전송·영구 저장·온라인 게시는 구현하지 않았으며, 페이지를 새로고침하거나 이동하면 목록이 사라집니다. 실제 업로드 서비스로 확장하려면 인증, 파일 저장소, 게시물 데이터 저장 기능이 필요합니다. 영상 샘플은 실제 제작 영상이 아닌 이미지 모션 기획 예시입니다.

본문과 프로젝트는 임시 예시이며, 갤러리 이미지는 AI로 생성했습니다. 온라인 글꼴 로딩이 불가능하면 시스템 기본 글꼴로 표시됩니다.
